## 문제 1 · 구조적 이상 탐지
정상 이미지만으로 정상 패턴을 학습하고, 테스트 이미지가 이상인지 판정합니다. 공개 개발용 `bottle`, 비공개 최종 평가용 `pill`.

| 항목 | 내용 |
|---|---|
| 방법 | PatchCore 방식. WideResNet-50-2의 layer2 + layer3 patch 특징으로 정상 memory bank 구성 |
| 점수 | patch마다 k=3 최근접 거리 평균, 이미지 점수는 patch 최댓값, 좌우반전 TTA |
| 임계값 | Calibration 20장에서 Macro F1 최대 구간의 중앙으로 고정 |
| 결과 | Bottle Macro F1 1.00 · Pill Calibration Macro F1 0.95 (AUC 0.97) |

## 문제 2 · Fashion-MNIST 라벨 노이즈
라벨이 오염된 Train 5,000장과 깨끗한 Reference 200장으로 Test 의류 클래스를 예측합니다.

| 항목 | 내용 |
|---|---|
| 진단 | 관측 라벨과 Reference 기반 예측의 일치율 0.38로 노이즈가 심하다고 판단 |
| 방법 | noisy 라벨로 표현만 짧게 학습 → Reference로 pseudo label 생성 → 확신 높은 샘플만 남겨 재학습 반복 |
| 선택 | Reference 50장을 홀드아웃으로 떼어 정제 회차 선택 (Macro F1 0.79), 3개 모델 앙상블 |
| 보정 | 클래스 균등 분포를 이용해 예측 분포 보정 |

## 돌아보며
- 두 문제 모두 정답 라벨이 부족하거나 믿을 수 없어서, 모델이 낸 점수를 그대로 쓰지 않고 "정상에서 얼마나 먼가"와 "얼마나 확신하는가"로 다시 걸렀습니다.
- 두 신호를 한 문제 안에서 함께 쓰면, 정상 중심에서 멀면서 확신도도 낮은 경계 샘플을 더 확실하게 골라낼 수 있을 것이라 봅니다.
- 평가용 샘플이 20장, 50장뿐이어서 그 점수에 계속 맞추는 것은 과적합이라 판단하고 튜닝을 멈춘 지점을 정한 것이 중요했습니다.
